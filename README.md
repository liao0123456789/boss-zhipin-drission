# Boss直聘投递助手

一个基于 DrissionPage + PyQt6 的 Boss 直聘自动化辅助工具，用于减少求职过程中的重复操作。

## 这个工具解决什么问题

在 Boss 直聘上求职时，需要反复浏览岗位、筛选条件、逐个投递，过程重复且耗时。这个工具通过图形界面配置筛选条件和打招呼语，自动完成岗位筛选和简历投递，帮助求职者把精力放在判断岗位是否合适上。

## 功能

- **自定义岗位名称**：设置要搜索的岗位关键词
- **自定义打招呼语**：设置投递时发送的招呼内容
- **筛选条件**：支持设置求职类型、薪资待遇、工作经验、学历要求、公司规模
- **运行日志**：实时提示每一步是否成功，方便排查问题
- **图形界面**：PyQt6 界面，操作简单
- **exe 版本**：已打包为 Windows exe，无需安装 Python 环境

## 技术栈

- **DrissionPage 5.0**：负责浏览器控制和页面元素操作
- **PyQt6**：负责图形界面
- **PyInstaller**：打包为 Windows exe
