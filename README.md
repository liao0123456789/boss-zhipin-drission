# Boss直聘投递助手

一个基于 DrissionPage + PyQt6 的 Boss 直聘自动化辅助工具，用于减少求职过程中的重复操作。

## 这个工具解决什么问题

在 Boss 直聘上求职时，需要反复浏览岗位、筛选条件、逐个投递，过程重复且耗时。这个工具通过自动化方式完成岗位筛选和简历投递，帮助求职者把精力放在判断岗位是否合适上。

## 适合谁用

- 正在使用 Boss 直聘求职、希望减少重复操作的人
- 对 Python 自动化、DrissionPage 感兴趣、想参考实现思路的开发者

## 不适合谁用

- 期望“批量海投、不看岗位”的人
- 需要保证 100% 不被平台风控的人（自动化操作始终有风险）

## ⚠️ 重要声明

## 功能

- 岗位筛选（按关键词、薪资范围等条件）
- 简历投递（自动化点击投递按钮）
- 图形界面（PyQt6），操作简单
- 支持打包为 exe，无需安装 Python 环境

## 技术栈

- **DrissionPage**：负责浏览器控制和页面元素操作
- **PyQt6**：负责图形界面
- **PyInstaller**：打包为 Windows exe
